A.1 DOCUMENT PROCESSING PIPELINE
================================================================================

```python
# PDF Loading and Chunking
from langchain_community.document_loaders import UnstructuredPDFLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter

loader = UnstructuredPDFLoader(file_path="textbook.pdf", mode="elements")
docs = loader.load()

text_splitter = RecursiveCharacterTextSplitter(chunk_size=400, chunk_overlap=100)
chunks = text_splitter.split_documents(docs)
```


A.2 VECTOR STORE CREATION
================================================================================

```python
# FAISS Vector Database
from langchain.embeddings import HuggingFaceEmbeddings
from langchain.vectorstores import FAISS

embedder = HuggingFaceEmbeddings(model_name="all-MiniLM-L6-v2")
vectorstore = FAISS.from_documents(chunks, embedder)
retriever = vectorstore.as_retriever(search_kwargs={"k": 5})
```


A.3 HyDE RETRIEVAL
================================================================================

```python
# Hypothetical Document Embeddings
from langchain_community.chat_models import ChatOllama

llm = ChatOllama(model="llama3.1:8b", temperature=0.3)

def generate_hypothetical_questions(topic, num=5):
    prompt = f"Generate {num} exam questions on: {topic}"
    response = llm.invoke(prompt)
    return response.split("\n")

def build_context_with_hyde(query, retriever, k_per_q=4):
    hypo_qs = generate_hypothetical_questions(query)
    all_docs = [retriever.get_relevant_documents(q)[:k_per_q] for q in hypo_qs]
    return "\n\n".join([d.page_content for docs in all_docs for d in docs])
```
